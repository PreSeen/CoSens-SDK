# CoSens SDK

本仓库按语言组织 SDK。Python SDK 已有本地可安装的首版实现；TypeScript 暂只预留目录。

| 目录 | 状态 |
| --- | --- |
| [python/](python/) | Python SDK 源码、测试与设计文档 |
| [typescript/](typescript/) | TypeScript SDK 预留位置，暂不开发 |

安装和运行示例见 [Python README](python/README.md)。三种接入方式、Session 消息游标和 RSI 原子接口调用时机见 [Python SDK 设计文档](python/docs/2026-10-26-cosens-python-sdk-design.md)。
