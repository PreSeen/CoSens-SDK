# CoSens Website Agent Rules

Read `/Users/derek/.agents/AGENTS.md` for shared instructions. The following rule is specific to this website repository.

## Commit and push every change

Every completed change to this repository must be committed and pushed to its configured remote branch before reporting completion. This includes code, content, styles, assets, documentation, and agent rules. Run the checks appropriate to the change before committing. Do not leave finished work only in the local checkout or as an unpushed commit.

If pushing fails or is blocked, preserve the local work, state the exact blocker, and report that the push is incomplete. Never force-push or overwrite someone else's changes to satisfy this rule. A successful push does not by itself prove deployment; follow the established deployment and live-verification workflow for website changes.
