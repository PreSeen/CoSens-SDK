# 中文客服 SLA 工具修复

业务：客服后台要按公司服务日历计算工单截止时间和累计服务分钟。现有 sla.py 在午休、假期、调休、时区和秒级边界产生错误。请修复代码，兼容以下两个公开纯函数，并新增自己的回归测试，交付 sla.py 与中文 修复说明.md。仅使用标准库，不得读写文件、联网或依赖进程全局可变状态；本地编写测试与说明不受此函数内部纯度约束。

接口：
- add_work_minutes(start_iso: str, minutes: int, calendar: dict) -> str
- work_minutes_between(start_iso: str, end_iso: str, calendar: dict) -> int

全部业务判定采用 UTC+08:00。输入为具有显式时区的 ISO-8601 日期时间，支持 Z 和 ±HH:MM 时区，保留整数秒，不接受小数秒或无时区日期时间。返回规范字符串 YYYY-MM-DDTHH:MM:SS+08:00。

calendar 为字典，必须包含 holidays 与 extra_workdays 两个字符串列表，列表元素须为严格 YYYY-MM-DD 的有效日期；列表可重复或改变顺序，但同一天不能同时出现在两类中，冲突须抛 ValueError。其他键可忽略。工作日为额外上班日，或周一至周五且非放假日；即调休上班可以发生在周末。公司日历是本题给出的仿真合同，不引用外部法定节假日。

每日工作窗口为 [09:00:00,12:00:00) 和 [13:00:00,18:00:00)，午休和其他时间不累计。正分钟数从非工作瞬间开始时，先跳到后续第一个工作瞬间。时长按真实秒数消耗，保留原有秒数；如果恰好在窗口末端耗尽，截止时间可以返回 12:00 或 18:00，不能继续跳窗。

minutes 只允许非负整数（bool、float、字符串都不行）。当 minutes=0 时，返回原始瞬间转为 +08:00 的值，即使它处于午休/假期，不需要跳到工作窗口。分钟数最大 20160，超过同样 ValueError。所有非法参数必须抛 ValueError，而不是其他异常或悄悄修正。

区间函数对 [start,end) 与全部工作窗口的交集累计真实秒数，最后统一向下取整为整数分钟；不能每段先取整再求和。例如跨午休的前后各30秒，应合计1分钟。end=start 返回0；end<start 抛 ValueError。跨时区输入按真实瞬间比较。

函数不得修改 calendar、其中的列表或任何调用者输入。连续调用不应相互污染。相同日历重排/重复条目不改变结果。对有效参数应满足：work_minutes_between(s,add_work_minutes(s,m,c),c)==m；分段追加满足 add(add(s,a),b)==add(s,a+b)，包括零分钟及恰好窗口末端。独立验收将覆盖公开规则边界与这些关系，不给模型隐藏样例或答案。不要按具体工单/日期硬编码。
